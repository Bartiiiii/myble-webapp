# Glossary EN ↔ CS (parts & hardware)

Engine identifiers → English → Czech trade term. Used by instructions,
part labels and the CS locale. (Czech strings to be confirmed by a native
speaker / cabinetmaker before they appear in customer-facing copy.)

## Part roles (`part.role`)

| id | EN | CS |
|---|---|---|
| `side` | side panel | bok (bočnice) |
| `top` | top panel | horní deska |
| `bottom` | bottom panel | dno |
| `shelf_fixed` | fixed shelf | pevná police |
| `shelf_adj` | adjustable shelf | přestavitelná police |
| `divider` | vertical divider | svislá příčka |
| `back` | back panel (HDF) | záda (HDF deska) |
| `door` | door | dvířka |
| `drawer_front` | drawer front | čelo zásuvky |
| `drawer_side` | drawer side | bok zásuvky |
| `drawer_back` | drawer back | záda zásuvky |
| `drawer_bottom` | drawer bottom | dno zásuvky |
| `plinth` | plinth / toe-kick | sokl |

| `rail` | rail / stretcher | vlys (výztužná lišta) |
